# Feature status

Release status of the Databricks features the starter uses, checked on 2026-10-22, with links to the Azure
Databricks documentation. The **Page date** is the "last updated" date of the linked page. Statuses change often;
check the linked page before relying on one.

What the release types mean (from [Azure Databricks preview releases](https://learn.microsoft.com/en-us/azure/databricks/release-notes/release-types)):
**Beta** features are off by default, enabled by an admin on the Previews page, not intended for production and
supported by the engineering team. **Public Preview** features are production-eligible, with a stable interface, an
SLA and support. **GA** features are fully supported.

| Unity Gateway model services | `05`, both agents | GA | [AI governance guide](https://learn.microsoft.com/en-us/azure/databricks/ai-gateway/ai-governance) (2026-10-19), [Custom model services](https://learn.microsoft.com/en-us/azure/databricks/ai-gateway/model-services) (2026-10-07) | Workspace must be in a Unity Gateway region ([region table](https://learn.microsoft.com/en-us/azure/databricks/resources/feature-region-support#model-serving-features-availability)). Created with the UI, REST API, SDKs, CLI, Terraform or bundles (Beta), not SQL. Needs `CREATE SERVICE` on the schema, `EXECUTE` on the destination model, and `CREATE TABLE` for inference logging. Model services use the owner's privileges on their destinations |
| Service policies (guardrails) | `05`, service assist | Beta | [Service policies for AI securables](https://learn.microsoft.com/en-us/azure/databricks/data-governance/unity-catalog/service-policies/) (2026-10-21) | Workspace admin enables the **Unity Ai Gateway Service Policies** preview. Built-in: `block_unsafe_content`, `block_jailbreak` (input only on model services), `block_hallucination` (output only), `detect_sensitive_data` (block or redact). Custom: SQL function or LLM-as-a-judge; external vendor policies are also supported. A DENY returns HTTP 200 with a `databricks_service_policy` object. Fail-closed; **Log** mode records the decision without blocking. Needs `MANAGE` on the service |

A model listed in `system.ai` can still fail with `404 ENDPOINT_NOT_FOUND`, so `01` makes a test call |
